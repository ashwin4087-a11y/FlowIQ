# Demo script

1. Start `npm run dev:all`
2. Confirm **BACKEND ONLINE** in header
3. Set traffic density LOW / MEDIUM / HIGH — watch 3D twin
4. Toggle **FESTIVAL SURGE (SIM)** — labeled simulated scenario
5. Press **DEMO EMERGENCY (SIMULATION ONLY)** — ambulance path + yield behavior
6. Upload a WAV under Audio Intelligence — requires trained model for real inference

Control mode always shows **DEMO / HEURISTIC**.
