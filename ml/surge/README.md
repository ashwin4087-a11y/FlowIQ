# FlowIQ Surge Predictor

Predicts **future** junction surge level (`LOW` / `MODERATE` / `HIGH`) from current traffic + signal features.

## Data (reproducible)

Generated by `src/generate_dataset.py` using the same logic family as `simulation/digital-twin/trafficSimulation.ts` (Python `simulator.py`). No external festival dataset.

**Target:** surge label at `t + 50 ticks` (2.5s sim time, dt=0.05) from future total queue length:

- HIGH: queue ≥ 14  
- MODERATE: queue ≥ 7  
- LOW: otherwise  

**Split:** by `episode_id` (grouped) ~70% train / 15% val / 15% test.

## Commands

```bash
cd ml/surge
pip install -r requirements.txt
python src/generate_dataset.py
python src/train.py
python src/evaluate.py
```

## Runtime features

See `src/features.py` — observable fields only (no hidden simulator density).

## Limitations

- Trained on **simulated** traffic, not real city probes.
- Short horizon prototype; not SUMO-calibrated.
- `traffic_mode_surge` reflects demo scenario flag, not a real festival calendar.
